# 🌱 KnowMitra – Campus Peer Learning Platform

**Learn Together. Share Skills. Grow Together.**

KnowMitra is a student-focused peer learning platform designed to connect college students who want to learn new skills, share their knowledge, and collaborate with other students.

The platform encourages collaborative learning by allowing students to teach skills they know and learn skills they want to improve.

---

## 🚀 Project Overview

KnowMitra provides a common platform where students can discover other learners, exchange skills, communicate, and build meaningful academic connections.

Instead of depending only on traditional learning methods, students can learn directly from their peers through skill exchange and communication.

## ✨ Key Features

- **Student Authentication:** User registration and login.
- **Student Profiles:** Create and manage personal profiles.
- **Skill Management:** Add and manage skills you can teach and want to learn.
- **Find Matches:** Discover students based on skill interests.
- **Browse Students:** Explore other student profiles.
- **Skill Exchange:** Send and manage skill exchange requests.
- **Real-Time Messaging:** Communicate with exchange partners.
- **Notifications:** Receive updates about platform activities and messages.
- **Photo Sharing:** Share images through conversations.
- **Audio & Video Calling:** Communicate with other students through calls.
- **Admin Account:** Dedicated administrative access for platform management.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd KnowMitra
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

For Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### 6. Configure Environment Variables

Create a `.env` file and configure the required application secrets and environment settings.

Never upload your `.env` file or passwords to GitHub.

### 7. Run the Application

```bash
python run.py
```

### 8. Open in Browser

```text
http://127.0.0.1:5000
```
